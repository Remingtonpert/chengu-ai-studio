# 辰鹄 AI 创作中心（Chengu AI Studio）

在自己电脑上出图、出视频、出音乐。不联网、不调云端接口，作品和数据都不离开本机。

## 能做什么

| 功能 | 说明 |
|---|---|
| 文生图 | 写一句话出图，中文直接写，不用翻译 |
| 图生图 | 给一张参考图，按你的描述重新画 |
| 文生视频 | 一句话生成几秒短视频 |
| 图生视频 | 让一张静态图动起来 |
| AI 音乐 | 描述风格和情绪，生成音乐 |
| AI 对话 | 本地小模型，离线可用 |

桌面程序和网页控制台两套界面，能力一致。

## 为什么选本地

- 作品不离开你的电脑，不经过任何云端服务
- 不用买算力，跑一次只花电费
- 断网也能用

## 硬件要求

- Windows 10 / 11
- NVIDIA 显卡，显存 6GB 起
- 内存 16GB 起
- 硬盘预留约 60GB 存放模型权重

## 快速开始

1. 安装 Python 3.11
2. 安装依赖

   ```
   python -m pip install -r requirements.txt
   ```

3. 下载模型权重（体积很大，不随仓库分发，首次运行会提示，也可手动运行 `scripts` 下的下载脚本）

4. 启动桌面端

   ```
   python -m app.bootstrap
   ```

   或者启动网页端

   ```
   powershell -File scripts\run_web.ps1
   ```
