# 辰鹄 AI 创作中心 · 使用说明书

（本说明书对应 2026-11-10 换型后的版本：文生图引擎已换成 Sana-1.6B 多语言版。桌面端与网页端功能、参数、文案完全一致，任何一处写在这里的说明两端都成立。）

## 一、这是什么工具

辰鹄 AI 创作中心是一台**完全本地、离线**的多模态创作工作站：所有模型都在你自己的机器上跑，不联网、不上传、不调用任何云端 API。同一台机器上可以用两种界面，它们共用同一条任务队列，产物也落在同一个目录：

- 桌面端：`scripts\run_app.ps1`（便携包里则是 `启动辰鹄.bat`），PySide6 原生窗口，共十个页面。
- 网页端：`scripts\run_web.bat`（或 `scripts\run_web.ps1`），然后在自己的浏览器打开 `http://127.0.0.1:8765`——服务只监听 127.0.0.1，局域网里的别人访问不到。

两种界面不用你操心谁先起：**桌面端启动时会顺手把网页端一起带起来**（同一份配置、同一条队列），所以只开桌面端也能直接在浏览器里打开 `http://127.0.0.1:8765`；已经有自家的网页端在监听就不重复起。桌面端是个窗口程序，它自己不监听任何端口，所以两端不会互抢端口；真撞上端口被第三方程序占了，网页端会自己往后挪一格（`8766`、`8767`…最多五格）继续跑，真实地址记在 `%LOCALAPPDATA%\ChenguAIStudio\logs\web-console.port`，`scripts\run_web.bat` 也认这个地址。不想让桌面端带网页端就把 `%LOCALAPPDATA%\ChenguAIStudio\config.json`（便携包里是包内 `data\apphome\config.json`）里的 `web_autostart` 改成 `false`；不想让它自己挪端口就把 `web_port_fallback` 改成 `false`（文件里没有这个键就自己加一行，加在最后一个 `}` 前面）。桌面端退出的时候，如果还有任务在排队或正在跑，网页端会故意留着不关，免得把跑了一半的任务砍断。

六个板块（顺序固定，两端一致）：

- **AI 智能体**：一句话指挥其余五个板块，也能写文案、做 Word/Excel/PPT。
- **文生图**：引擎 `sana-multiling`（Sana-1.6B 多语言版），中文、英文、中英混合提示词都认。
- **图生图**：引擎 `wan-i2i`（Wan2.1-VACE-1.3B），按垫图参考重绘，产出一张 PNG。
- **文生视频**：引擎 `wan-t2v`（Wan2.1-T2V-1.3B）。
- **图生视频**：引擎 `wan-i2v`（Wan2.1-VACE-1.3B 首帧条件）。
- **AI 音乐**：引擎 `ace-step-15`（ACE-Step 1.5），48kHz wav，可带中英文人声或纯器乐。

选型三条硬标准（所有引擎都满足）：**权重可商用** / **原生支持中英文提示词** / **真机峰值显存不超过 6GB**。FLUX 一类的大模型已明确排除并从项目里删除。

## 二、第一次使用前的准备

1. 安装四个 Python 环境（互不干扰，缺哪个就不注册哪个引擎）：
   - `.venv`：桌面端与网页端主环境（不需要 torch）。
   - `.venv-image`：文生图（Sana），脚本 `scripts\setup_image_venv.ps1`。
   - `.venv-video`：图生图与两个视频引擎，脚本 `scripts\setup_video_venv.ps1`。
   - `.venv-music`：AI 音乐，脚本 `scripts\setup_music_venv.ps1`。
2. 下载权重（全部走 Hugging Face 缓存布局，可离线复用；国内网络默认走镜像 `hf-mirror.com`）：
   - 文生图：`python scripts\download_sana_weights.py` → `models\sana-multiling`（9.06GB）。
   - 图生图 + 视频：`python scripts\download_video_weights.py` → `models\wan2.1`（44.18GB，两处共用同一套权重，不会下载两遍）。
   - AI 音乐：`python scripts\download_music_weights.py` → `models\ace-step-1.5`（9.4GB）。
   - 智能体的大模型：`models\llm\gguf\Qwen3-8B-Q4_K_M.gguf`，由项目自带的 `tools\llama_cpp` 运行，**不需要装 Ollama**。
3. 自检：`python scripts\verify_env.py`（缺环境、缺权重、显存/内存门槛都会点名说清楚，不会假装就绪）。
4. 打开真实引擎：设置页里把 `engines_enabled` 打开。默认关闭是为了在你确认许可与下载之前绝不动你的硬盘。

缺权重不会崩：对应引擎直接不注册，界面上会写「引擎未注册」并点名缺什么（例如文生图会提示需要 `.venv-image` 与 `models\sana-multiling`，并给出 `scripts\download_sana_weights.py`）。历史任务记录里的旧引擎（`sd-realvis`、`wan-t2i`）仍能正常查看，不会被删或读不出来。

## 三、日常使用的基本规矩

- **一条串行队列**：图片、视频、音乐、智能体共用同一条 FIFO 队列，同一时刻只有一个模型进显存。切换板块不会把两份权重同时搬进显卡。
- **一次出一张**：文生图与图生图每次 1 张（旧的 SD1.5「说一句出 4 张」随旧引擎退场）。要不同风格就换提示词或换 seed 多跑几次。
- **seed**：「不固定」= 每次随机；「固定」= 可复现同一张图 / 同一段视频 / 同一段音乐。
- **提示词**：中英文都认（文生图尤其强，原生支持中英混合与 emoji）；负面提示词只有文生图、图生图、视频档有。
- **产物位置**：默认写到程序设置里的产物目录（`output\`），文件名自带引擎与时间戳，例如 `sana_txt2img_20261110_153012.png`。设置页可以看/改产物目录，也能开启自动另存到指定文件夹。
- **在哪看产物**：图片点开是大图查看器；视频和音频**都在工具里播放**，不再甩给系统播放器。桌面端点视频卡片（或卡上的「▶ 播放」）弹出工具内播放窗：播放/暂停、进度条、音量、另存、打开所在文件夹，窗口关掉解码器就释放。网页端视频卡片本身就是播放器，按卡上的 `⛶`（或双击视频）在灯箱里放大播放。视频任务除 mp4 外还会同时写一张同名 `…-first.png` 首帧封面（只当封面用，「另存」取的始终是 mp4 本体）。
- **网页端小习惯**：Enter 提交（Shift+Enter 换行）；看大图时 Esc 关闭，← / → 切换上一张/下一张。

## 四、文生图（Sana-1.6B 多语言版）

**能做什么**：中文、英文、中英混合提示词直接写，不用翻译；1024 级分辨率直出；要更高分辨率时引擎自己按像素预算出底图再放大。

**默认与范围**：

- 尺寸默认 **1024×1024**，宽高都是 **32 的倍数**，单边 320–2048。
- 六档预设（两端逐字相同）：`1:1 1024`、`16:9 1024级`（1152×640）、`9:16 1024级`（640×1152）、`4:3 1024级`（1152×864）、`3:4 1024级`（864×1152）、`16:9 1080p（放大）`（1920×1088）。
- **单遍像素预算 1,100,000px**：超过它的目标尺寸（例如 1920×1088）会由引擎按预算出底图（1376×768 左右），再等比放大 + 居中裁边到目标尺寸；产物元数据里 `upscaled=true`。这不是「高清重绘」，也不会新增画面细节，只是干净地把尺寸提上去——界面与元数据都如实这么写。
- 目标尺寸上限 4,200,000px；单边超过 2048 会先夹到 2048，不会报错。
- 步数默认 **20**，范围 **10–40**（官方推荐 20 步）；CFG 固定 4.5，**不是用户参数，界面上没有 CFG 滑杆**。
- 种子、负面提示词有；**没有**重绘强度、**没有**分块高清重绘开关、**不接受输入图片**。

**明确做不了的事**（写在这里是为了少踩坑）：想「按参考图改一张」请去**图生图**板块（引擎 `wan-i2i`）；在文生图板块提交带参考图或带 `strength`（重绘强度）、`hires`（分块高清重绘）的请求会被明确拒绝并说明原因，不会静默丢掉参数。

**显存与内存**：Sana 的 fp16 权重合计 9.06GB，其中文本编码器单件约 5GB，因此引擎按「逐件换入 GPU」的方式跑，绝不把整套权重常驻显存（那会超过 6GB）。加载前的门槛：空闲显存 ≥5120MB 走模型级卸载，≥1500MB 走逐层卸载，低于 1500MB 直接拒绝起跑并点名是谁占着显存；另外要求空闲物理内存 ≥16GB（`CHENGUAI_SANA_MIN_FREE_RAM_MB` 可调）。**峰值显存目前是按 6GB 档位推算的预期值，尚未真机实测**——一键验收脚本见第九节，实测数字出来后以实测为准。

## 五、图生图（Wan2.1-VACE）

- 必须先放垫图（本机绝对路径，可拖进来或 Ctrl+V 粘贴），再用提示词描述要改成什么样。
- 语义是「按参考重绘」（VACE 参考生成），不是把垫图逐帧锁定，也不是简单滤镜。
- 尺寸是 **16 的倍数**，480p 档像素预算（约 0.46MP），默认 832×480；五档预设：`16:9 480p`、`9:16 480p`、`1:1 480p`、`4:3 480p`、`3:4 480p`。
- 步数默认 28。要 1024 级的高像素出图请改用文生图板块。
- 产物是单帧 PNG；「变体」「放大」在图生图出的图与老的历史记录上走这条参考重绘链路，具体见下面第三小节。

### 产物卡片上的「V 变化」与「U 放大」到底做什么

两个按钮在网页端与桌面端**同名、同参数、同一套分流规则**，点下去排的是**新任务**，原图不动。分流只看**这张源图当初是哪个引擎出的**，与你在哪个板块点它无关（在视频板块点图片卡片也不会把任务塞给视频引擎）。

- **源图来自文生图（`sana-multiling`）**——Sana 不接受垫图（diffusers 这一版没有 Sana 的图生图管线），所以：
  - **U 放大**：同一个提示词、同一个 seed，按更大尺寸**重新出图**。目标尺寸取 1.34 倍后对齐到 32 的倍数，单边不超过 2048，总像素不超过 4,200,000；超过单遍预算 1,100,000px 时引擎按预算出底图、再等比放大 + 居中裁边到目标尺寸（产物元数据 `upscaled=true`）。比例不变时潜空间网格不变，构图与源图一致；多出来的像素是放大来的，**不会新增画面细节**，界面与元数据都如实这么写。
  - **V 变化**：同一个提示词、原尺寸、**换 seed** 重新出图 1 张（换 seed 本身就是新构图）。seed 规则两端一致：源任务有整数 seed 就取「源 seed + 1」（变体链可复现），没有就发一个新的随机 seed；绝不会沿用源 seed，否则等于把同一张图重排一遍。
- **源图来自图生图（`wan-i2i`），或 2026-11-10 之前的老文生图历史记录**——走图生图参考重绘，源图当垫图：
  - **U 放大**：按 1.34 倍的目标尺寸重绘，尺寸对齐到 16 的倍数、单边不超过 1024、总像素夹进 480p 档预算 459264px（超了就等比缩回）。
  - **V 变化**：原尺寸、换 seed（同样是「源 seed + 1」或新随机 seed）再重绘 1 张。
- 两个动作都**一次只排 1 张**（串行队列 + 6GB 显存档位；旧 SD 时代的 4 连发已随引擎退场）。图生图引擎没有「重绘强度」参数，改动幅度由提示词决定。
- 已经到各自上限附近时会直接拒绝并说清原因（「已在 Sana 的目标硬上限 / 480p 档像素预算上限附近，无法再放大；要更大尺寸得另配超分或更大的模型」），不会假装放大。
- 在文生图板块点 U/V，排出来的任务仍属文生图（板块显示 `t2i`）；在图生图链路则属图生图（`i2i`）。


## 六、文生视频 / 图生视频

- 引擎：`wan-t2v`（纯文字描述动态画面）、`wan-i2v`（先放首帧图，再描述怎么动）。
- 尺寸同样是 16 倍数、480p 像素预算，并且另有一条 20000 tokens 的 6GB 显存档位闸门（token = 宽/16 × 高/16 × 压缩后帧数）。**档位钉死**：你选什么档位就按什么档位出片，不会自动降档、也不会偷改帧数；超线的组合在提交前就挡下，并把这一档的真实上限讲成具体数字（保持该分辨率最长几帧、保持该帧数最大分辨率），你自己二选一。桌面端面板与网页端在提交前用同一份数字算，不会让用户白提交一次。
- **时长**：帧数 5–161，自动取到 4n+1（Wan 时间压缩约束），导出固定 **16fps mp4**；界面会显示「× 秒 / × 帧 @16fps」。越长越吃显存与时间。
- 步数默认 28；负面提示词有；**没有**「运动幅度」这类参数——Wan2.1 不暴露它，界面上那个控件是禁用占位，不改变任何行为。
- 视频档真机实测峰值约 2021MB（6GB 档位设计：bf16 + 逐层 CPU 卸载）。
- **看片（两端一致）**：卡片上直接显示首帧封面，点开就在工具内播放——桌面端是播放窗（进度/音量/另存/文件夹），网页端是卡片内嵌播放器加 `⛶` 放大播放。历史视频任务（没有封面图的那种）卡片会写「没有首帧预览，点开仍可在工具内播放」，点开照样能播。

## 七、AI 音乐

- 引擎 ACE-Step 1.5（MIT 许可），**48kHz wav** 输出（wav 是无压缩 PCM，不是「有损 mp3」）。
- 可带人声（中英文歌词）或纯器乐；风格预设（如电子、钢琴等）会拼进提示词。
- **目标时长** 30–480 秒（引擎白名单 10–480，超出会被截到上限，产物按真实时长为准）。
- 步数：turbo 推荐 **8 步**（默认），加到 16–30 步质量更好、耗时成倍增加。
- 首次生成要加载约 9.4GB 权重（LM/DiT 走 CPU 卸载），通常 1–3 分钟；显存不足会被引擎明确拦截，不会半路炸掉。
- **播放**：两端都在卡片里播（桌面端是卡片内播放条，网页端是 `<audio controls>`）。放不出来时卡片会写明原因（缺解码器、文件已不在、时长读不出来等），并保留「改用系统播放器」这条退路——不会出现按了没反应、也不会在没告知的情况下偷偷换播放器。

## 八、显存与内存不够时怎么办

- 界面在提交前会先释放自己拉起的大模型服务，再实测空闲显存；低于门槛会**拦下提交并点名是哪个程序占着显存**。
- 手动清场：`scripts\release_local_engine.bat`（释放本地 LLM/引擎占的显存）。
- 门槛：视频/音乐板块要求空闲显存 ≥6144MB；文生图/图生图沿用同一道 6144MB 门槛（比引擎自身的下限更严，保证不会踩到 6GB 红线）。
- 显卡被别的程序占着时，最稳的做法是关掉占用者再跑；验收脚本在空闲显存或空闲内存不足时会**直接拒绝起跑**，跑到一半实测峰值超过 6000MB 会**立即停止**后续测试，不会继续压显卡。

## 九、自检与验收脚本（都在 `scripts\`）

- `verify_env.py`：环境 + 权重 + 门槛自检，逐项点名。
- `acceptance_image.bat` / `acceptance_image.py`：文生图一键验收（纯中文 + 中英混合两条提示词，1024×1024 与 1920×1088 两档；起跑前查空闲显存/内存，不足就停；实测峰值超 6000MB 立即停止）。
- `acceptance_video.py`、`acceptance_music.py`：视频、音乐验收（同样先查门槛）。
- `acceptance_chain.ps1`：按 image → video → music 顺序串起来跑，每一步都先过门槛。
- `smoke_desktop_generation.py`、`shot_desktop_ui.py`：不加载权重的界面/链路冒烟。
- `check_hardware.py`：读显卡型号、显存与物理内存，判断哪几个板块现在跑得动。
- `build_portable.ps1`：打便携包（带走四个 venv 与现役权重 `sana-multiling`、`wan2.1`、`ace-step-1.5`、`llm\gguf`；已下架的 SD1.5 三件套故意不打包）。

## 十、常见问题

- **「引擎未注册」**：缺对应 venv 或权重。提示会写明要跑哪个脚本，照做即可。
- **提交后被拒绝并说「不接受输入图片 / 没有重绘强度 / 没有分块高清重绘」**：这是故意的。你在文生图板块用了只属于图生图的参数，换板块或去掉该参数。
- **想稳定复现**：把 seed 固定，其他参数不变。
- **1080p 出图为什么慢/为什么不更细**：超过 1,100,000px 的目标走的是「底图 + 等比放大」，清晰度受底图像素限制，属于引擎档位设计，不是故障。
- **浏览器打开 `http://127.0.0.1:8765` 说「无法访问 / 连接被拒绝」**：网页端服务当时没在跑，不是网页端坏了。现在只要桌面端起来了就会顺手把网页端带起来；只想开网页端就双击 `scripts\run_web.bat`（它会把「是不是别人占了端口」「服务在不在」说清楚）。真起不来时看 `%LOCALAPPDATA%\ChenguAIStudio\logs\web-console.err.log` 的最后几行。
- **网页端界面还是旧样子**：静态资源带版本号（`?v=20261111b`），刷新即可拿到新版；若仍显示旧的，清一次浏览器缓存。
- **中文乱码**：命令行里先 `chcp 65001`（脚本入口已经这么处理），或设 `PYTHONUTF8=1`。
- **测试项目时显卡占用过高**：立刻停止，不要继续。测试脚本都带门槛与「超峰值即停」的保护。

## 十二、这一版已经不再提供的东西

- **`wan-t2i`（Wan 单帧文生图）已下架**：它本质是视频引擎的副作用，分辨率被 480p 视频预算卡死，界面上不会再出现第二个「文生图」。代码与注册都已移除。
- **SD1.5 + RealVis（`sd-realvis`）不上架、不注册、界面不可见**：它的 CLIP 只认英文，不满足「中英文」这条，只作为本机后备留在盘上。
- **FLUX 权重与引擎已删除**（23GB，超出显存，且用户明确否决）。
- 文生图/图生图「一次 4 张」的批量、`strength`/`hires` 参数、CFG 滑杆等，都不再出现在文生图板块。
