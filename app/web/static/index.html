参数设置

引擎

生成尺寸（480p 档像素预算）

时长

导出固定 16fps（Wan 原生）；帧数自动取到 4n+1（时间压缩约束），越长越吃显存与时间。

运动幅度

Wan2.1 不暴露运动幅度参数；此控件保留为禁用占位，不改变任何默认行为。

Steps

文生图（Sana）默认 20 步（引擎范围 10-40）；Wan 图生图/视频档默认 28 步；ACE-Step turbo 音乐档默认 8 步（推荐）。

Seed

不固定时每次随机；固定时同一 seed 可复现同一段视频/同一张图/同一首曲子。

负面提示词

风格 / 曲风（点击追加到提示词）

音乐引擎状态

已接入 ACE-Step 1.5（权重 MIT，本地离线推理，无云端 API；按 6GB 显存档位设计，LM/DiT 走 CPU 卸载，峰值显存为预期值、尚未实测，验收以任务元数据 peak_vram_mb 为准）。支持带人声（中英文）完整乐曲或纯器乐，时长 10-480 秒，输出 48kHz wav；不支持超长多轨道复杂编曲。提交前会检查显存并弹出能力边界确认；显存不足会直接拦截。

BPM

目标时长

合法范围 10-480 秒，超出会被引擎夹到边界，产物按真实时长为准。

人声 / 纯器乐

勾选纯器乐时不生成人声；带人声时歌词由本地 LM 依风格描述自动创作，语言按上面选择（中英文）。

高级参数（JSON，可选）

白名单：width height steps seed negative_prompt init_image_path num_frames；init_image_path 需为盘符开头的绝对路径，且指向已存在的具体图片文件（png/jpg/jpeg/webp/bmp），不能是文件夹；num_frames 只对视频板块生效

产物保存

生成好的内容在本工具里即时显示，产物写在输出目录 读取中…；同时固定复制一份到工具内 output 目录 读取中…（输出目录本来就指着它时不会重复复制）。

自动另存到本地硬盘（可选）
